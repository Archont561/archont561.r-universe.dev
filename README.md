# Archont561 R-Universe

Welcome to the personal R package universe for [@Archont561](https://github.com/Archont561), powered by the [r-universe.dev](https://r-universe.dev) platform.

This repository serves as the central manifest and distribution hub for R packages developed and maintained across this ecosystem.

### What is this Universe?

This universe functions as an autonomous, CRAN-compatible package repository that bridges development repositories with end-user R environments:

- **Automated Multi-Platform Binaries**: Packages are continuously built, tested, and compiled into native binaries for Windows, macOS (Apple Silicon & Intel), and multiple Linux distributions.
- **Zero-Dependency Installation**: Users can install packages with standard base R `install.packages()` without requiring local C/C++ toolchains, compilers, or GitHub authentication tokens.
- **Automated Tracking & Synchronization**: Tracks upstream Git repositories and tags, regenerating binaries, manual pages, and documentation whenever releases are published.
- **REST APIs & Package Feeds**: Provides machine-readable endpoints for package status, dependency trees, commit provenance, and build telemetry.

### Connecting to this Universe in R

To use this universe as an active CRAN mirror in your R session:

```r
options(repos = c(
  archont561 = "https://archont561.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Or using `pak`:

```r
pak::repo_add(archont561 = "https://archont561.r-universe.dev")
```

### Automated Registry Discovery

`packages.json` and the table above are regenerated automatically — don't
edit either by hand. The [Discover R packages](.github/workflows/discover-packages.yml)
workflow runs daily (04:17 UTC, also runnable on demand) and:

- scans every public, non-fork, non-archived `Archont561/*` repository for a
  `DESCRIPTION` file — that file (not GitHub language or topics) defines an
  R package, and `package`, `url`, and `subdir` are derived from it;
- preserves per-package fields it cannot derive (e.g. `branch`) from the
  current `packages.json`, and keeps manual entries pointing outside
  `Archont561/*` untouched;
- rebuilds the **Released Packages** table above — a package tracking
  `"branch": "*release"` appears once its repository has a published
  GitHub release, with links to this universe, its source, the release,
  and its docs; until then it is listed as awaiting its first release;
- opens a **pull request** (`auto/registry-sync`) instead of pushing directly,
  so additions and removals are reviewed before R-universe picks them up.

Three scripts (sharing `.github/scripts/registry_common.py`) do the work:

| Script | Purpose |
| :--- | :--- |
| [`discover.py`](.github/scripts/discover.py) | Scan `Archont561/*` and rebuild `packages.json` |
| [`add_package.py`](.github/scripts/add_package.py) | Add (or `--update`) one package; name/subdir inferred from its `DESCRIPTION` for GitHub repos |
| [`update_readme.py`](.github/scripts/update_readme.py) | Rebuild the Released Packages table between its markers (`--check` fails if stale) |

Run them locally (falls back to your `gh` login if no token is set):

```bash
python3 .github/scripts/discover.py --dry-run        # preview registry
python3 .github/scripts/discover.py                  # rewrite packages.json

python3 .github/scripts/add_package.py Archont561/<new-repo>
python3 .github/scripts/add_package.py https://github.com/<owner>/<repo> --branch "*release"
python3 .github/scripts/add_package.py https://gitlab.com/<owner>/<repo> --package <pkgname>

python3 .github/scripts/update_readme.py             # refresh the table above
python3 .github/scripts/update_readme.py --check     # verify it is current
```

Discovery behavior is configured in
[`.github/registry-discovery.json`](.github/registry-discovery.json):
`exclude_repos`, `exclude_packages`, and per-package `overrides` — set an
override value to `null` to remove a preserved field such as `branch`.
Discovery warns when a package tracks `"branch": "*release"` but its
repository has no published GitHub release (R-universe has nothing to build).
